# DRG Conditions — current playtest inventory

FROZEN: exclude Conditions from initial seven-card hands; add after pre-race exchange. On draw, reveal/place immediately in active Condition area, draw a replacement until the required normal-card draw count is met, and do not consume a voluntary play. Newly drawn Conditions act that turn. No maximum number of active Conditions.

Each physical Condition tracks immutable **Base Severity**, permanently treated **Current Severity**, and **Effective Severity** after temporary suppression, minimum zero. Penalties and restrictions apply only while Effective Severity is positive. A nonpersistent Condition at Current Severity zero is discarded; a persistent one remains managed unless expressly removed. Named remedies set Current Severity to zero; Aid removes Twisted Ankle entirely. Gear changes Effective Severity only, so its removal restores the penalty from unchanged Current Severity. Anti-Chafe prevents a new Hot Spot while active and has no effect on one already present.
